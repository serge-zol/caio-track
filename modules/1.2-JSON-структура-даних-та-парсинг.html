що таке JSON

JSON — мова між програмами

Якщо API — це «дверний дзвінок» між сервісами, то JSON — це «мова», якою вони спілкуються. Більшість сучасних API передають дані саме в форматі JSON.

JSON (JavaScript Object Notation) — текстовий формат запису структурованих даних. Читається людиною і парситься будь-якою мовою програмування. Версія 2001 року, RFC 8259 (2017).

Ти вже бачив JSON — це те, що повертає API у відповідь на запит. Webhook-повідомлення від Stripe, відповідь Claude API, дані від Google Calendar — все це JSON.

анатомія JSON

JSON будується з двох базових конструкцій:

{ } Об'єкт (Object)

Набір пар ключ: значення. Ключі — завжди рядки в лапках. Порядок не гарантований.

[ ] Масив (Array)

Впорядкований список значень. Нумеруються з 0. Можуть містити будь-які типи.

JSON — базова структура 
{
  "name": "Сергій",
  "age": 32,
  "active": true,
  "score": null,
  "skills": ["API", "JSON", "Make"],
  "address": {
    "city": "Київ",
    "country": "UA"
  }
}
Ключове правило: JSON — це завжди текст (string). Коли API «повертає JSON» — він повертає рядок. Програма потім «парсить» цей рядок у нативний об'єкт своєї мови.

JSON vs XML vs YAML

Формат Де використовується Читабельність Вага
JSON REST API, webhooks, конфіги Висока Легкий
XML SOAP API, старі системи Середня Важкий
YAML Docker, CI/CD, конфіги Дуже висока Легкий
Для автоматизацій (Make.com, n8n, Zapier) JSON — стандарт де-факто. 95%+ сучасних API використовують саме його.

правила синтаксису

✓ Ключі в подвійних лапках ✓ Рядки в подвійних лапках ✓ Крапка з комою між парами ✗ Без коментарів ✗ Без trailing comma ✗ Без одинарних лапок
Типові помилки
// ❌ НЕПРАВИЛЬНО
{
  'name': "Сергій",      // одинарні лапки для ключа
  "age": 32,
  "city": "Київ",         // trailing comma
}

// ✅ ПРАВИЛЬНО
{
  "name": "Сергій",
  "age": 32,
  "city": "Київ"
}

6 типів даних JSON

STRING "..."

Текст у подвійних лапках. Підтримує Unicode, escape-символи.

NUMBER 42

Ціле або з плаваючою крапкою. Без лапок. Науковий запис ок.

BOOLEAN true

Тільки true або false. Завжди в нижньому регістрі.

NULL null

Відсутність значення. Аналог None, nil, undefined.

ARRAY [...]

Впорядкований список. Індекси з 0. Будь-які типи всередині.

OBJECT {...}

Пари ключ-значення. Ключ — тільки рядок. Вкладеність необмежена.

приклади всіх типів

JSON — всі 6 типів
{
  // STRING — текст
  "username": "serge_zol",
  "emoji": "🚀",
  "path": "C:\\Users\\file.txt",   // escape

  // NUMBER — числа
  "age": 32,
  "price": 149.99,
  "big": 1.5e10,

  // BOOLEAN
  "verified": true,
  "deleted": false,

  // NULL
  "avatar": null,

  // ARRAY
  "tags": ["AI", "automation", "CAIO"],
  "scores": [95, 87, 92],

  // OBJECT (вкладений)
  "location": {
    "lat": 50.45,
    "lon": 30.52
  }
}

доступ до значень (JavaScript)

JavaScript — доступ до даних
const data = JSON.parse(jsonString);

// Dot notation
data.username           // "serge_zol"
data.location.lat     // 50.45

// Bracket notation (для динамічних ключів)
data["age"]             // 32

// Масиви — індекс з 0
data.tags[0]          // "AI"
data.tags[2]          // "CAIO"
data.tags.length       // 3

// Серіалізація назад у рядок
JSON.stringify(data, null, 2)  // відступ 2 пробіли

доступ у Python

Python — json module
import json

# Парсинг рядка → dict
data = json.loads(json_string)

# Доступ
data["username"]           # "serge_zol"
data["location"]["lat"]  # 50.45
data["tags"][0]            # "AI"

# Безпечний доступ
data.get("missing", "default")  # "default"

# Серіалізація dict → рядок
json.dumps(data, indent=2, ensure_ascii=False)

cheat sheet — шляхи до даних

JavaScript / JSON Path

data.name Пряме поле об'єкта
data.user.email Вкладений об'єкт
data.items[0] Перший елемент масиву
data.items[0].id Поле з першого елементу
data.items.length Кількість елементів

Make.com / n8n шляхи

{{data.name}} Пряме поле (Make)
{{data.user.email}} Вкладений (Make)
{{data.items[].id}} Ітерація масиву (Make)
$json.name n8n expression
$json.items[0].id n8n — елемент масиву

JSON.parse / stringify

JSON.parse(str) Рядок → об'єкт
JSON.stringify(obj) Об'єкт → рядок
JSON.stringify(obj,null,2) З відступами (pretty)

Python json module

json.loads(str) Рядок → dict
json.dumps(obj) Dict → рядок
data.get("key",def) Безпечний доступ

реальні JSON з API

Stripe → твій сервер: При успішній оплаті Stripe надсилає POST-запит з таким тілом. Потрібно витягти data.object.amount та data.object.customer_email.
Stripe — payment_intent.succeeded
{
  "id": "evt_3PqR...",
  "type": "payment_intent.succeeded",
  "created": 1748520000,
  "data": {
    "object": {
      "id": "pi_3Pq...",
      "amount": 4999,          // cents → $49.99
      "currency": "usd",
      "status": "succeeded",
      "customer_email": "user@example.com"
    }
  }
}
event.type
→
event.data.object.amount
→
/ 100 = $49.99
Claude API відповідь: Потрібно витягти текст — content[0].text. Також важливі: usage.input_tokens та usage.output_tokens для контролю витрат.
Claude API — /v1/messages response
{
  "id": "msg_01XFD...",
  "type": "message",
  "role": "assistant",
  "content": [
    {
      "type": "text",
      "text": "Привіт! Як можу допомогти?"
    }
  ],
  "model": "claude-sonnet-4-20250514",
  "stop_reason": "end_turn",
  "usage": {
    "input_tokens": 25,
    "output_tokens": 12
  }
}
Зверни увагу: content — це масив. Тому текст: response.content[0].text, а не response.content.text.
Google Calendar API: Відповідь при отриманні події. Критично: start.dateTime vs start.date — різниця між подіями з часом та цілоденними.
Google Calendar — event object

  "id": "7qr8st...",
  "summary": "Зустріч з командою",

    "dateTime": "2026-05-30T10:00:00+03:00",
    "timeZone": "Europe/Kiev"
  },
  "end": {
    "dateTime": "2026-05-30T11:00:00+03:00"
  },
  "attendees": [
    { "email": "you@gmail.com", "responseStatus": "accepted" }
  ]
}
GitHub → webhook при push: Автоматизація — наприклад, при push до main відправляти повідомлення в Telegram. Витягуємо pusher.name та commits[0].message.
