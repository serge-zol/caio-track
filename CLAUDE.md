# CLAUDE.md — Інструкції для роботи з CAIO Track

## Перша дія в кожній сесії

Перед будь-якою роботою прочитати:
1. `00_plan/ПЛАН.md` — поточний статус кроків
2. `01_knowledge/база_досвіду.md` — накопичені інсайти
3. `01_knowledge/контекст.md` — середовище та підхід

## Структура проекту

| Папка / файл | Призначення |

| `00_plan/ПЛАН.md` | Живий план: всі етапи, кроки, статуси |
| `01_knowledge/база_досвіду.md` | Інсайти та архітектурні рішення по ходу навчання |

| `README.md` | Навігація + зведений статус |

## Правила після завершення кожного кроку

1. Оновити статус кроку в `ПЛАН.md`
2. Додати запис в `база_досвіду.md`
3. Оновити `README.md` — статус модуля і план
4. Commit + push

## Загальні правила

- Перед редагуванням таблиць — читати формат існуючих рядків
- Перевіряти результат після кожної дії (verify-then-tick)
- Мова: українська
